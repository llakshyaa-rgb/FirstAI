Images & files

Uploads are limited to 20 MB per batch. Files stay in Orbit’s local upload folder until deleted; use Delete uploaded file to remove an item. Do not expose this prototype server on an untrusted public network. Common images preview; text, PDF, modern Office, OpenDocument, EPUB and supported archives can be read. Optional backends add scanned-PDF OCR, audio transcription and video analysis. Other formats can be stored without being interpreted. Newly uploaded files are queued for your next chat.
